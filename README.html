FeiSharpCodeEditor_WinForm.net8.0 README

I. Project Overview

This project is a Windows form application based on.NET 8.0 for editing FeiSharp code. It provides functions such as code editing, saving, running, and checking, and also has certain interactive logic and syntax-parsing capabilities.

II. Main Functional Modules

(I) Main Window (MainForm)

Event Handling

  • Keyboard Events (KeyDown, KeyPress): Handled in the Form1_KeyDown and Form1_KeyPress methods. For example, pressing the F5 key runs the code (Run method), Ctrl + S saves as (SaveAs method), Ctrl + F opens a file (Start method), etc. At the same time, some special shortcut key combinations, such as Ctrl + Alt + C to close the window, are also handled.
  • Mouse Events (MouseDown, MouseClick): Handled in the MainForm_MouseDown and txtCode_MouseClick methods. For example, right-clicking in the text box pops up the corresponding context menu.
  • Window Resize Event (Resize): Handled in the FeiSharpForm_Resize method. It limits the minimum window size and adjusts the widths of the text box and the output box.

Function Button Click Events

  • Run Button (BtnRunClick): Clicking the run button calls the Run method, which performs lexical analysis (Lexer) and syntax analysis (Parser) and displays the results or error messages in the output box.
  • Save As Button (BtnSaveAsClick): Clicking the save as button calls the SaveAs method, which saves the current code to the specified file through the SaveFileDialog.
  • Open File Button (BtnOpenFileClick): Clicking the open file button calls the Start method, which opens the FeiSharp source file through the OpenFileDialog and loads it into the text box.
  • Check Button (BtnCheckClick): Clicking the check button calls the Check method to perform code checking, including checking the legality of variable and function names and runtime exceptions.
  • Menu Button (BtnMenuClick): Click to display the menu.
  • Shortcut Button (BtnShortcutClick): Create a desktop shortcut for the application.
  • Log Button (log_Click): Click to show or hide the log window.

Code-editing-related Functions

  • In the CodeEditor_KeyPress method, handle the input of specific characters (such as (, ") in the text box, automatically complete parentheses or quotation marks, and display intelligent prompts according to the input content (ShowIntelligenceIfNecessary method).
  • In the txtCode_TextChanged method, update the intelligent prompts according to the changes in the content of the text box.

(II) Syntax Parser (Parser)

  • Constructor: Accepts a list of Tokens as a parameter to initialize the state of the parser, including setting the current position, built-in variables (true and false), etc.
  • Parse Statements (ParseStatements): This method is the core of syntax parsing. It processes various types of statements, such as variable declarations (var), print statements (print), function definitions (func), conditional statements (if), loop statements (while), etc. The code is parsed by matching keywords and corresponding syntax structures.
  • Evaluate Expression (EvaluateExpression): Used to calculate the value of an expression, supporting numbers, strings, variables, binary operations (+, -, *, /, etc.), and performing corresponding calculations and type conversions according to the expression type and operator.
  • Other Functional Methods: Such as MatchToken, MatchKeyword, MatchPunctuation, MatchOperator, etc. are used to match different types of Tokens to assist the syntax-parsing process. There are also Advance, Peek, Previous, etc. methods for moving and obtaining Tokens in the Token stream.

III. Data Structures and Types

  • Token Type: Represents the basic syntactic units in the code, including keywords (Keyword), identifiers (Identifier), numbers (Number), strings (String), punctuation marks (Punctuation), operators (Operator), end-of-file markers (EndOfFile), types (Type), boolean values (Bool), function names (FuncName), etc.
  • Data Structures in Parser
    • _tokens: Stores the list of parsed Tokens.
    • _current: The index of the current parsing position.
    • _variables: A dictionary that stores variables and their values.
    • _functions: A dictionary that stores function information, including function names, parameter lists, and lists of function-body Tokens.
    • _results: A dictionary used to store the return results of functions.

IV. Usage Methods

  • Start the Application: Run the executable file to open the main window of FeiSharpCodeEditor.
  • Edit Code: Enter FeiSharp code in the text box.
  • Save Code: Click the save as button and select the save path and file name.
  • Run Code: Click the run button to view the output results or error messages.
  • Check Code: Click the check button to check the legality of the code and potential problems.
  • Use Shortcut Keys and Menus: Execute corresponding operations through shortcut keys or by clicking menu buttons, such as creating shortcuts, opening files, etc.

V. Precautions

  • The exception-handling part in the code is used to capture syntax-parsing and runtime errors, but the error-message-prompting information may need to be further improved and optimized to better help users locate problems.
  • When handling intelligent prompts and code-editing-related functions, attention should be paid to performance optimization, especially when dealing with large-scale code files, to avoid lagging.
  • For the syntax of the FeiSharp language, it is necessary to ensure that the implementation of the parser is completely consistent with the language specification to avoid parsing errors or incorrect execution results.
